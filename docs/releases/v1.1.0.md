# v1.1.0

Functional comparison between `master` (v1.0.0) and `feature/amelioration-performances`.

## Dependency Graph — *New*
- **New "Dependency Graph" tab.** A searched bench appears at the center of an interactive graph of its direct relations (depends-on / supports / shared resource), with support for selecting several benches at once as independent centers.
- **Progressive graph exploration.** Right-clicking any bench in the diagram lets you add its dependencies, add its shared resources, or hide it — the diagram builds up progressively, across multiple levels, with automatic layout avoiding card overlap.
- **Local diagram save.** A compact menu lets you save, reload, or list diagrams you've built (positions, links, selection), directly in the browser.
- **Diagram export / import.** A saved diagram can be downloaded as a file and shared with a colleague, who imports it into their own list.
- **Display settings.** A settings panel lets you choose which information is visible on each card (status, type, city, building/room) and adjust card width to avoid truncated text.
- **Visual reading of links.** Links are colored by their nature (dependency, shared resource) and drawn dashed when the dependency is optional (solid for mandatory coupling).

## Dependency View — *New*
- **New "Dependency View" tab.** Shows every bench matching the active filters arranged in a circle, with their relations drawn as curves passing through the center; hovering a bench highlights its outgoing and incoming links.
- **Individual list refinement.** A checklist of the currently filtered benches lets you show/hide each one individually, with search and "select all" / "deselect all" actions.
- **Adjustable display limit.** The maximum number of benches shown on the view (previously fixed) is now adjustable via a slider.

## Catalogue and Bench Detail — *Improved*
- **Fifth bench type.** Added the "SHARED RESSOURCE" type, accounted for everywhere (filters, detail pages, PDF export, icons).
- **Draft / Release state tag.** Every bench now shows a "DRAFT" (grey) or "RELEASE" (green) badge according to its state, in both the catalogue and its detail page.
- **"Quality Seal" filter.** A new 3-position filter (Draft / All / Release) is available on the catalogue, map, and Dependency View.
- **Filters preserved across navigation.** Catalogue filters are preserved when navigating to and back from a bench detail page, but reset when returning explicitly via the "Catalogue" menu item.

## PDF Export — *Improved*
- **New bench detail page layout.** The PDF detail page is reorganized (header, centered photo, 3-column band, full-width sections) to more closely match the web detail page.
- **Airbus branding.** Added the Airbus logo to the header and replaced "bench(es)" with "Lab Test Mean(s)" throughout the document.

## Photo Loading — *Improved*
- **Loading indicator.** A spinner now displays on each photo (catalogue card, detail page) while it loads, which can take several seconds.
- **Configurable offline photo cache.** A new global setting enables/disables a photo cache kept between visits, lets you set its maximum size, view space used, and clear it — avoids re-downloading photos already seen.
- **Manual data refresh.** A new button in the header forces a reload of bench/aircraft-program data without reloading the whole page.
