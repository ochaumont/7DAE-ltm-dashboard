# v1.0.0

> **Note:** this project's git history does not carry dated, versioned releases (commit messages are terse, e.g. `update`). This entry is a **reconstructed baseline** — the feature set present on `master` before the work described in [v1.1.0](v1.1.0.md) — not a changelog pulled from tagged releases.

## Baseline feature set
- **Catalogue** (`/`) — paginated grid of bench cards with basic filtering.
- **Map** (`/map`) — MapLibre view of geo-located benches across the four known sites.
- **Lab Test Mean detail** (`/labtestmean?id=`) — photo gallery, security/access, lifecycle timeline, people, and programs/projects for a single bench.
- **PDF export** — an early version of the bench detail export, predating the 3-column redesign and Airbus branding described in v1.1.0.
- **Basic dependency list** — dependencies were available as a flat, untyped list on each bench, without a dedicated graph view, direction, or relation type (depends-on / supports / shared resource) — the capability the Dependency Graph and Dependency View screens in v1.1.0 were built to replace.
- **Health check** (`/health`) — static status endpoint for deployment probes.
